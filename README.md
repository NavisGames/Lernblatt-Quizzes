# Quiz-Lernhub

Der Einstieg ist [index.html](index.html). Der Lernhub und die Lernseiten können direkt im Browser geöffnet werden.

## Aufbau

- `shared/`: gemeinsame Quiz-Anwendung, Gestaltung und Skripte für Lernseiten.
- `DVT-13-1/` und `Informatik-13-1/`: Fragen, Lernseiten, Lernblätter und fachspezifische Rechner für das 1. Semester der 13. Klasse. Ihre `index.html`-Dateien leiten zum Lernhub weiter.
- `Mathematik-12-1/` und `Mathematik-12-2/`: Fragen, Lernseiten und Lernblätter für Analysis beziehungsweise Stochastik.
- `vendor/temml/`: eingebundene Bibliothek zur Darstellung mathematischer Formeln mit ihren Lizenzen.

Die PDFs liegen im jeweiligen Fachordner. Ältere direkte Links auf Fachseiten und PDFs müssen an die neuen Ordnernamen angepasst werden.
