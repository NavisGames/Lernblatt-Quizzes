01 · ÄnderungSekante, Tangente und Ableitung

Die mittlere Änderungsrate beschreibt die durchschnittliche Veränderung zwischen zwei verschiedenen Stellen. Geometrisch ist sie die Steigung der Sekante durch beide Punkte.

Mittlere und lokale Änderungsrate mmittel = (f(x₂) − f(x₁)) / (x₂ − x₁),   x₂ ≠ x₁ f′(x₀) = limh→0 [f(x₀ + h) − f(x₀)] / h Für den Differenzenquotienten gilt h ≠ 0. Sein Grenzwert ist die Tangentensteigung und lokale Änderungsrate.

Musterlösung: Ableitung aus dem Grenzwert

Für f(x) = x² und x₀ = 2 verwenden wir (2 + h)² = 4 + 4h + h². Der Differenzenquotient ist (4 + 4h + h² − 4)/h = 4 + h für h ≠ 0. Für h → 0 folgt f′(2) = 4.

Typische Falle

h darf im ursprünglichen Bruch nicht null sein. Erst den Ausdruck für h ≠ 0 vereinfachen und danach den Grenzwert betrachten. Bei (a + b)² den Mittelterm 2ab nicht vergessen.

Deutung in Sachaufgaben

Weg s in Metern und Zeit t in Sekunden: [s(t₂) − s(t₁)]/(t₂ − t₁) ist die mittlere Geschwindigkeit in m/s; s′(t₀) die momentane Geschwindigkeit. Für Kosten K(x) in Euro und Menge x in Stück beschreibt K′(x) die lokale Kostenänderung in Euro pro Stück. Temperatur- oder Höhenänderungen werden genauso mit passenden Einheiten interpretiert.

Tipp: Schreibe die Einheit immer als Einheit des Funktionswerts pro Einheit der Eingabe. Achte auf das Vorzeichen und auf den betrachteten Zeitraum.

Typische Falle

Im Argument wirkt der Faktor b reziprok: g(2x) ist horizontal gestaucht, nicht gestreckt. Die Definitionsmenge muss nach einer Transformation erneut geprüft werden.

03 · AbleitungenRegeln und höhere Ableitungen
RegelAbleitung
Konstante / Potenz(c)′ = 0; (xⁿ)′ = nxⁿ⁻¹ auf dem jeweiligen Definitionsbereich.
Faktor / Summe(c·u)′ = c·u′; (u ± v)′ = u′ ± v′.
Produkt(uv)′ = u′v + uv′.
Quotient(u/v)′ = (u′v − uv′)/v², wobei v ≠ 0.
Kette(u(v(x)))′ = u′(v(x)) · v′(x).
Weitere(eˣ)′ = eˣ; (aˣ)′ = aˣ ln a für a > 0; (ln x)′ = 1/x für x > 0; (sin x)′ = cos x; (cos x)′ = −sin x.

Wurzeln und Brüche zunächst als Potenzen schreiben: √x = x1/2, 1/x² = x−2. Daraus folgen für x > 0: (√x)′ = 1/(2√x), und für x ≠ 0: (1/x²)′ = −2/x³. Die Randstelle x = 0 muss separat betrachtet werden.

Musterlösungen

Kettenregel: f(x) = (3x + 1)⁴. Außen ableiten: 4(3x + 1)³; innen ableiten: 3. Also f′(x) = 12(3x + 1)³.

Produktregel: f(x) = x·eˣ. Daher f′(x) = 1·eˣ + x·eˣ = (1 + x)eˣ. Für f(x) = x⁴ ergeben sich f′(x) = 4x³, f″(x) = 12x² und f‴(x) = 24x.

Typische Falle

Bei Produkt und Quotient nicht einfach beide Faktoren getrennt ableiten und multiplizieren bzw. dividieren. Bei verketteten Funktionen die innere Ableitung nicht vergessen.

04 · KurvenMonotonie, Extrempunkte, Krümmung und Geraden

Eine Kurvendiskussion beginnt mit Definitionsbereich und gegebenenfalls Symmetrie, Achsenschnitten und Grenzverhalten. Danach f′ und f″ bestimmen, kritische Stellen berechnen und Vorzeichen auf Intervallen untersuchen.

KriteriumDeutung
f′ > 0 / f′ < 0Streng steigend / streng fallend auf dem betrachteten Intervall.
f′(x₀) = 0Notwendig für einen inneren Extrempunkt einer differenzierbaren Funktion; allein nicht hinreichend.
f″(x₀) > 0 / < 0Bei f′(x₀) = 0 hinreichend für lokales Minimum / Maximum. Bei f″(x₀) = 0 Vorzeichenwechsel von f′ prüfen.
f″ > 0 / f″ < 0Linksgekrümmt (konvex) / rechtsgekrümmt (konkav). Ein Wendepunkt erfordert einen Krümmungswechsel.

Monotonieschema: Kritische Stellen auf dem Zahlenstrahl markieren und in jedem Intervall das Vorzeichen von f′ prüfen. Wechsel + → −: Hochpunkt; − → +: Tiefpunkt. Randstellen und nicht differenzierbare Stellen gegebenenfalls gesondert untersuchen.

Musterlösung: f(x) = x³ − 3x: f′ = 3x² − 3 = 3(x − 1)(x + 1). Das Schema ist + | − | + auf (−∞, −1), (−1, 1), (1, ∞). Hochpunkt (−1|2), Tiefpunkt (1|−2). Aus f″ = 6x folgt ein Krümmungswechsel bei (0|0).

Tangente und Normale in P(x₀|f(x₀))t(x) = f′(x₀) · (x − x₀) + f(x₀)mn = −1 / f′(x₀),   n(x) = mn(x − x₀) + f(x₀)Die Normalenformel gilt nur für f′(x₀) ≠ 0. Bei waagerechter Tangente ist die Normale die vertikale Gerade x = x₀.

Beispiel: f(x) = x² bei x₀ = 1: P(1|1), mt = 2. Tangente t(x) = 2x − 1; Normale n(x) = −½(x − 1) + 1.

Typische Falle

f″(x₀) = 0 allein beweist keinen Wendepunkt: Bei f(x) = x⁴ wechselt f″ = 12x² an 0 nicht das Vorzeichen.

05 · AnwendungenExtremwerte und Ortskurven

Vorgehen: Skizze und Größen festlegen; Zielfunktion und Nebenbedingung aufstellen; Nebenbedingung einsetzen; zulässigen Bereich bestimmen; Ableitung null setzen und innere Kandidaten sowie zulässige Randwerte vergleichen; Ergebnis mit Einheit deuten.

Musterlösung: Zaun und Rechteck

Ein Rechteck hat Umfang 20 m. Mit Seiten x und y gilt 2x + 2y = 20, also y = 10 − x. Die Zielfunktion ist A(x) = x(10 − x) für 0 ≤ x ≤ 10. A′(x) = 10 − 2x = 0 ergibt x = 5; A″ = −2 < 0. Die Randwerte liefern Fläche 0. Maximum: 5 m × 5 m mit 25 m².

Weitere Modelle

  • Offene Kiste: Aus einem Quadrat der Seite 10 werden Ecken der Seite x entfernt: V(x) = x(10 − 2x)², für positive Abmessungen 0 < x < 5.
  • Geschlossene Dose: V = πr²h und Oberfläche O = 2πr² + 2πrh. Für festes V ist h = V/(πr²), r > 0; diese Nebenbedingung in O einsetzen.
  • Rechteck unter einer Kurve: Bei y = 4 − x², einer Grundseite auf der x-Achse und symmetrischen oberen Ecken (±x|4 − x²) ist A(x) = 2x(4 − x²) für 0 ≤ x ≤ 2.

Ortskurven

Bei einer Funktionenschar ft werden beispielsweise die Extrempunkte E(t) = (x(t)|y(t)) ermittelt. Löse x(t) nach t auf und setze das Ergebnis in y(t) ein. Beachte Einschränkungen des Parameters und der erhaltenen x-Werte.

Beispiel: ft(x) = (x − t)² + t hat den Tiefpunkt E(t) = (t|t). Mit x = t folgt als Ortskurve y = x.

Typische Falle

Die Ableitungsnullstelle ist nur ein Kandidat. Sachbereich, Randwerte und Art des Extremums entscheiden über die Lösung.

06 · FolgenZahlenfolgen und Grenzwerte

Eine Folge ordnet jedem natürlichen Index n einen Wert an zu. Eine explizite Vorschrift berechnet an direkt; eine rekursive verwendet vorherige Glieder und benötigt ausreichende Anfangswerte.

Ab Index 1Arithmetisch: an = a₁ + (n − 1)d,   an+1 = an + dGeometrisch: an = a₁qn−1,   an+1 = q·an

Beispiele: a₁ = 2, d = 3 ergibt a₅ = 2 + 4·3 = 14. Bei a₁ = 3, q = 2 ist a₄ = 3·2³ = 24.

Monotonie und Beschränktheit

an+1 − an > 0 für alle n bedeutet streng steigend, < 0 streng fallend. Der Quotient an+1/an kann bei positiven Gliedern entsprechend mit 1 verglichen werden; bei null oder negativen Gliedern ist Vorsicht nötig. Eine obere Schranke S erfüllt an ≤ S für alle n; eine untere Schranke s erfüllt an ≥ s.

Konvergenz und ε-Umgebung

an konvergiert gegen L, wenn zu jedem ε > 0 ein N existiert, sodass für alle n ≥ N gilt: |an − L| < ε. Ab N liegen also alle Glieder in (L − ε, L + ε). 1/n → 0; (−1)ⁿ divergiert trotz Beschränktheit: Die geraden Glieder sind 1 und die ungeraden −1. Für |q| < 1 gilt a₁qn−1 → 0.

Grenzwertsätze und rationale Folgen

Konvergente Folgen dürfen gliedweise addiert und multipliziert werden. Für Quotienten muss der Nennergrenzwert ungleich null sein. Bei rationalen Ausdrücken mit n durch die höchste auftretende Potenz teilen.

Musterlösung: (2n² + 3)/(n² − 1) = (2 + 3/n²)/(1 − 1/n²) → 2/1 = 2. Einzelne nicht definierte Indizes müssen ausgeschlossen werden; für den Grenzwert zählt das Verhalten für große n.

Typische Falle

Ein Nennergrenzwert von null erlaubt keine direkte Anwendung des Quotientensatzes. Untersuche den Ausdruck gesondert; weder 0/0 noch eine Division durch null ist ein Ergebnis.
