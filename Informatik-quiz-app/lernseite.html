TCP: SYN → SYN+ACK → ACK. Die empfangsseitige Fenstergröße begrenzt die Flusssteuerung; die Überlastkontrolle passt die Sendemenge an die vermutete Netzlast an.

02 · Endpunkte und Web

IP, Port und Socket

Eine IP-Adresse erreicht einen Host oder Netzwerkendpunkt. Eine Portnummer unterscheidet Anwendungen auf diesem Host. Ein Socket ist die Kombination IP-Adresse:Port, zum Beispiel 192.168.1.5:1099.

PortbereichBezeichnung
0–1023Well-known Ports
1024–49151Registrierte Ports
49152–65535Dynamische/private Ports

Eine URI identifiziert eine Ressource. Eine URL lokalisiert sie mit Schema, Host, optionalem Port, Pfad, Query und Fragment. HTTP läuft standardmäßig über TCP 80, HTTPS über TCP 443 mit TLS.

03 · Anwendungsdienste

DNS, HTTP und FTP

DNS löst Namen über Resolver und hierarchische DNS-Server auf. Standardport 53 wird sowohl über UDP als auch TCP verwendet.

Ein Browser löst den Hostnamen auf, baut zu Ziel-IP und 80/443 eine TCP-Verbindung auf und fordert mit HTTP/HTTPS eine Ressource an.

FTP verwendet TCP 21 als Steuerkanal. Beim aktiven Modus öffnet der Server den Datenkanal typischerweise über TCP 20; beim passiven Modus handelt der Client einen Datenport aus.
